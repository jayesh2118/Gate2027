# GATE 2027 Preparation OS

A Vercel-ready React + Vite + Tailwind personal preparation dashboard.

## Included
- Custom editable GATE 2027 countdown
- GATE CS syllabus tracker
- Four topic states: Not Started / In Progress / Completed / Revision
- Editable month-wise Study Plan
- Drag-and-drop subjects between months
- Date-range planning
- Study Plan → Daily Tracker sync
- Calendar Daily Tracker
- PYQ, Mock Test and Resources sections
- Analytics
- LocalStorage persistence
- JSON backup export/import
- Responsive mobile sidebar

## Run
npm install
npm run dev

## Production build
npm run build

## Deploy
Push the project to GitHub and import the repository into Vercel.
No backend or environment variables are required for this version.
